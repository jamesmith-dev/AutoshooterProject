# Introduction 
This is a project intended for COP4934 (Senior Design) at UCF
Our project is a top-down ARPG auto-shooter survival game built in Unreal Engine 5.
Set within an endless procedurally generated world, players are placed in the center of relentless enemy waves that spawn from all directions.
While the character automatically targets and attacks the enemies, the player's challenge is to maneuver through the chaos, dodging incoming attacks and tactically positioning themselves to maximize damage output.
This mix of automatic targeting with player-controlled movement introduces a layer of strategy, where survival depends on quick thinking and precise execution.
